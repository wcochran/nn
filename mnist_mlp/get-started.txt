- Output layer: 10 neurons

- Loss: cross entropy
- Training: mini-batch stochastic gradient descent

Use Eigen for all matrix/vector math.

Please implement this cleanly and explicitly, without using a machine learning framework.

- Educational clarity over maximum performance
- Explicit forward pass

- Update weights and biases using SGD

- db2 += delta2
- delta1 = (W2.transpose() * delta2).cwiseProduct(ReLUPrime(z1))
- dW1 += delta1 * a0.transpose()
- db1 += delta1
